# vector-humanities.github.io

Landing page for [Vector Humanities](https://github.com/vector-humanities), served by GitHub Pages at <https://vector-humanities.github.io>.

Static HTML, CSS and JavaScript with no build step. `index.html` is the page; `assets/field.js` draws the hero's flow field; `assets/style.css` holds the light and dark themes. To preview locally:

```bash
python3 -m http.server 8842
```
